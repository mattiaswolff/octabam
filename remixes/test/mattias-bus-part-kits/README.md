# MIDI Part settings with KITS

Integration candidate selecting the personal bus modules, native MIDI Part
state, Follow, Scales, Harmony and upstream KITS. No DEG or MIDI SCENES.
KITS source and storage are unchanged. This selection isolates Part-owned
settings from the degree task's separate conversion integration.

The module settings must also work in the corresponding selections without
KITS. Full Kit library/project lifecycle and hardware acceptance are pending;
a successful image build is not that evidence.
