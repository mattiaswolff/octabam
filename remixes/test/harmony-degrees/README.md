# Harmony degrees

Isolated selection for the [degree-based Harmony replacement](../../../modules/midi-harmony/degrees/README.md).
Includes MIDI Scales so all seven modes are exercised. The existing
`midi-harmony` selection remains the control.

This selection builds with `make bus REMIX=harmony-degrees BUILD=D0`.
Degree component and full-firmware port evidence is documented with the
[personal-bus D0 candidate](../../mattias-bus-degrees/README.md), which is the
packaged hardware-validation selection. Hardware acceptance remains open.
