# Mattias bus with Harmony degrees

Separate hardware-validation candidate for the
[Harmony degree replacement](../../modules/harmony-degrees/README.md), using
the same audio effects and MIDI modules as [mattias-bus](../mattias-bus/README.md).

This selection is a production implementation candidate, not a reduced prototype.
It is not merged into the current module or release. No firmware has yet been
packaged or accepted on hardware. Use a complete copy of a project for acceptance.

The final package must contain the immutable source reference, image SHA-256,
validation commands/results and manual acceptance scenarios from the module plan.
